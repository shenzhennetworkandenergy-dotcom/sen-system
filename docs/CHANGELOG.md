# SEN Platform Changelog

## 2026-07-30 — Integrated Human Resources (local review)

- Added administrator-only employee lifecycle management with archive and restore.
- Added departments, teams, designations, work locations, and reporting relationships.
- Added attendance entry/import, employee history, and correction approval workflows.
- Added leave types, balances, employee requests, approval/rejection, audit records, and notifications.
- Added payroll periods, payroll components, payment status, performance reviews, and goals.
- Added protected employee documents and private storage policies.
- Added protected employee, department, attendance, leave, and payroll CSV exports plus a printable report.
- Added employee self-service HR routes.
- Added attendance-device registration and a secured, idempotent event-ingestion API for future fingerprint/camera gateways.
- Added HR validation, static verification, database smoke verification, and documentation.

No raw biometric data or biometric templates are stored by SEN.
